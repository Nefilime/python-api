## Проект: Simple REST API (Flask)

Это очень простой RESTful API на Flask, демонстрирующий базовую структуру для использования в пайплайнах и PoC (proof of concepts).

---

### 📁 Структура проекта

```
python-api/
├── app.py           # Основной Flask-приложение
├── Dockerfile       # Контейнеризация
├── requirements.txt # Зависимости
└── README.md        # Документация
```

---

### 🎯 Функциональность

| Рут | Метод | Описание |
|-----|-------|----------|
| `/` | GET   | Возвращает список всех дней недели |
| `/:<id>` | GET  | Возвращает конкретный день по ID (1-7) |
| `/` | POST  | Принимает POST-запросы (без обработки данных) |

---

### 🔧 Технологический стек

- **Backend**: Flask
- **Python**: 3.12.4 (slim)
- **Контейнеризация**: Docker
- **CI/CD**: GitHub Actions
- **Безопасность**: Trivy (сканирование уязвимостей)

---

### 🚀 Деплой

```bash
# Локальный запуск
python app.py
curl 127.0.0.1:5000/
```

**Контейнеризация:**
```bash
docker build -t python-api .
docker run -p 8000:8000 python-api
```

### ⚠️ Рекомендации по улучшению

| Проблема | Рекомендация |
|----------|--------------|
| Нет валидации запросов | Добавить проверку JSON и типы данных |
| Hardcoded data | Перенести данные в отдельный файл/базу |
| Отсутствует логирование | Использовать logging вместо print |
| Нет тестирования | Добавить pytest-тесты |
| POST эндпоинт пустой | Реализовать логику обработки данных |

---

**Вердикт**: Идеально подходит для демонстрации базовых принципов API, CI/CD и Dockerизации. Для продакшена требует дополнительных доработок по безопасности, тестированию и обработке ошибок.
